# Quanh Lab — Textbook navigation internationalization v58

25 October 2026 · Fix and coverage report.

## Root cause

The earlier textbook implementation translated selected static HTML text nodes, but the bookshelf was generated by `book-reader.js` after loading `books/catalog.json`. The 85 lesson options, 15 chapter names, grade dropdown, book title and accessible image labels were generated as Vietnamese strings and were excluded from the old DOM translation pass.

## Changes

- `dist/book-copy.js`: manually edited English titles for all **85** lessons in 3 grades and all **15** chapter headings. The titles reflect the existing Vietnamese navigation labels and high-school physics vocabulary; they do not replace the source textbooks.
- `dist/book-reader.js`: uses localized metadata **at render time** for cards, all chapter/lesson options, cover labels, page status, single/spread view and fullscreen buttons. Locale switches update the existing reader elements without re-fetching pages, resetting zoom or mutating current-page storage.
- `dist/book-language.js`: translates the surrounding static navigation and accessible labels, including skip navigation, and displays a precise English note distinguishing localized navigation from original Vietnamese page scans.
- Home library book previews now translate Physics 10/11/12, cover alternative text and their series label.
- The English chapter dropdown is width-constrained on smaller screens.

## Scope and source verification

The original `dist/books/catalog.json` is unchanged. All **388 page images** are unchanged; book chapter and lesson identifiers, internal page offsets and printed page numbers are unchanged. The English navigation metadata is independent from the original Vietnamese study materials. No publisher's textbook content is copied or distributed as a new translation.

English physics terminology and quantity names use ordinary internationally accepted usage and were cross-checked against existing Quanh Lab references and the BIPM SI conventions:
- https://openstax.org/books/physics/pages/1-introduction
- https://www.bipm.org/en/publications/si-brochure

The 85 English navigation labels are editorial translations of labels, not a translation of each textbook's printed pages or an independently certified full English textbook.

## QA

Run `node checks/book-english-v58.mjs`, `node checks/language-pill-v57.mjs`, `node checks/books.mjs`, `node checks/touch-books-v41.mjs`, then `npm run check`. CI/DOM evidence cannot substitute for physical iPhone/Safari testing. Manual acceptance should cover a cold EN load, switching EN → VI → EN while at page 50 and zoomed, every grade's 85 lesson options, keyboard and screen-reader focus, and 320–440 px/mobile landscape viewport widths.
